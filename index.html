繰り返しは for (...) { ... } と while (frontIsClear()) { ... }、条件分岐は if (...) { ... } else { ... } が使えます。

自分の関数も function walk() { move(); } と定義して walk(); で呼び出せます。ゲーム用の安全な学習環境のため、一部のJavaScript構文だけを使えます。
